# Tanzi AI – Multilingual Health Assistant

Tanzi AI is a full-stack AI-powered health assistant designed to improve access to healthcare information for low-literacy communities.

The application provides a symptom checker, conversational chatbot, and triage guidance in multiple languages.

## Features

- AI-powered symptom checking
- Multilingual chatbot (English & Chichewa)
- Smart triage and referral logic
- Secure backend API architecture
- Responsive mobile-first interface

## Tech Stack

Frontend:
- React.js
- JavaScript
- Tailwind CSS

Backend:
- Node.js
- Express.js
- REST APIs

Database:
- MongoDB

AI Integration:
- AI API for conversational health guidance

## Architecture

The application follows a full-stack architecture:

Client → React frontend  
Server → Node.js + Express REST API  
Database → MongoDB
